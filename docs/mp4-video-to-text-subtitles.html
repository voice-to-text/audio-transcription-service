Extract text and subtitles from MP4 video

Drop MP4 recordings, screen captures, and lectures to generate ready-to-use SRT and WebVTT captions.

Download Release View on GitHub

Automatic audio track selection

When an MP4 file contains H.264 or HEVC video alongside AAC audio, the decoder skips video tracks and extracts only the audio stream for Whisper.

Built-in video playback with captions

Selecting a completed MP4 item opens an HTML5 video player connected to the local byte-range server so you can seek by clicking transcript lines.

Sidecar SRT and VTT ready for editors

Subtitle files land next to the MP4 with matching base filenames, ready for DaVinci Resolve, Premiere, Final Cut, or HTML5 video players.

lecture.mp4 -> lecture.txt + lecture.srt + lecture.vtt
