Batch transcription queue that survives restarts

Queue dozens of recordings at once with per-file progress, isolated errors, and persistent disk recovery.

Download Release View on GitHub

Non-blocking background worker

A dedicated worker thread processes queued items sequentially while the UI and Watch Folder remain responsive.

Error isolation

Corrupted files, unsupported extensions, and read-only folder errors log into the Error Log and mark only that item Failed, while remaining items continue.

Automatic resume after restart

Closing the app mid-queue preserves queue_state.json on disk. Reopening resets in-flight Decoding, Transcribing, or Exporting items back to Queued and finishes them.

queue_state.json -> Decoding/Transcribing on crash -> reset to Queued on launch
