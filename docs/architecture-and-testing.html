Architecture, restart recovery, and testing

One shared codebase compiles native desktop installers for macOS and Windows while keeping background queue state safe on disk.

Shared macOS and Windows codebase

The desktop shell uses Tauri 2 and React 19, while all media decoding, directory watching, queue scheduling, and file export logic runs in Rust. On Windows, subprocess calls to whisper-cli.exe set CREATE_NO_WINDOW so background recognition runs without flashing console windows.

Queue persistence and crash recovery

Every queue change writes atomically to queue_state.json. If the app is closed mid-batch while items are in Decoding, Transcribing, or Exporting, the next launch resets those interrupted entries to Queued and resumes the worker loop without losing any files.

Built-in media streaming player

A lightweight loopback HTTP server on 127.0.0.1:4895 serves local audio and video files with HTTP 206 Partial Content byte-range responses. When you click a segment timestamp in React, the HTML5 player seeks directly to that millisecond offset.

End-to-end test coverage

Run node tests/run_e2e_tests.mjs against the release binary to verify all formats (MP3, WAV, M4A, MP4), languages (English, Russian, mixed), durations (10s, 5m, 1h), background noise, multi-speaker dialogue, pure silence, 10-file watch folder copy stability, duplicate skipping, error handling, restart recovery, and clean startup.
