Architecture, recovery, and end-to-end tests

One shared codebase compiles native apps for macOS and Windows while keeping queue state safe on disk.

Download Release View on GitHub

Modular Rust backend

Decoding (audio.rs), Whisper CLI execution (whisper.rs), atomic export (export.rs), queue persistence (queue.rs), folder watching (watcher.rs), and HTTP streaming (api.rs) run independently of the UI thread.

10-scenario end-to-end suite

Run node tests/run_e2e_tests.mjs against the compiled release binary to test all four formats, EN/RU/mixed speech, 10s/5m/1h durations, noise, multi-speaker dialogue, silence, 10-file watch folder, duplicates, errors, restart recovery, and byte-range playback.

Cross-platform CI builds

GitHub Actions workflow .github/workflows/build.yml builds and tests on macos-latest and windows-latest.

cd src-tauri && cargo test
node tests/run_e2e_tests.mjs
