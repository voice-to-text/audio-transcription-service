Whisper desktop app with Watch Folder and player

Use whisper.cpp with ggml-base.bin through a native Tauri 2 and React interface instead of terminal flags.

Download Release View on GitHub

No command-line setup for daily work

Running whisper-cli manually requires converting MP4 or M4A audio to 16 kHz mono WAV first and shifting timestamps across long chunks. Audio Transcription Studio automates decoding, chunking, inference, and export.

Multilingual GGML model support

Place ggml-base.bin or another GGML model in models/ or your OS application support directory. Each speech chunk runs with automatic language detection.

Visual queue and error log

Track progress per file from 0% to 100%, inspect corrupted inputs in the Error Log, and re-run any file manually with one click.

whisper-cli -m models/ggml-base.bin -f chunk_0000.wav -l auto -oj -np -sns
