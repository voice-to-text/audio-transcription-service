WAV to text transcription on desktop

Process studio WAV recordings, field recorder clips, and voiceovers locally with exact millisecond timings.

Download Release View on GitHub

Direct PCM and IEEE float support

Symphonia reads standard 16-bit PCM, 24-bit PCM, and 32-bit float WAV containers at any sample rate and normalizes them to 16 kHz mono for whisper.cpp.

Silence detection for clean tracks

Studio recordings with silent lead-ins or pure silence clips skip inference when RMS stays below the noise floor, preventing spurious Whisper text.

Clickable segment verification

Play back the WAV file in the built-in player and click any segment row to jump straight to that millisecond.
