Skip duplicate audio files automatically

Every transcribed file is fingerprinted with SHA-256 so copies and re-drops are skipped instantly.

Download Release View on GitHub

Content-based deduplication

Before running Whisper, Audio Transcription Studio hashes the file with SHA-256 and checks processed_hashes in queue_state.json.

Copy-safe Watch Folder behavior

Renaming or copying an already processed audio file into the Watch Folder marks it Skipped (Duplicate) once existing TXT, SRT, and VTT outputs are verified.

Manual override when needed

If you update models or want a fresh pass, click Re-transcribe on any item to force a new run.

sha256(file) in processed_hashes && outputs exist -> status: skippedDuplicate
