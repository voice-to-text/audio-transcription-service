Create numbered SubRip cue files beside every recording with monotonic millisecond timings.

Download Release View on GitHub

Standard SubRip formatting

Each cue includes a sequential index, HH:MM:SS,mmm start and end timestamps with comma separators, and trimmed speech text.

Multi-chunk offset alignment

For 5-minute and 1-hour files split across multiple VAD chunks, each chunk offset in milliseconds is added to Whisper segment offsets so cues align with the full timeline.

Atomic writes next to source

SRT files write to a temporary file and rename atomically so video editors never read half-written subtitle files.
