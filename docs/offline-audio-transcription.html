Offline audio transcription app without internet

Turn recordings into TXT, SRT, and VTT files on your own hardware with zero network calls.

Download Release View on GitHub

Why transcribe locally

Cloud transcription services require uploading private interviews, client meetings, and raw voice notes to third-party servers. Audio Transcription Studio keeps every byte on disk. Audio decoding, voice activity segmentation, Whisper inference, and subtitle writing run inside one desktop app.

Supported inputs and outputs

Drop MP3, WAV, M4A, or MP4 files into the window or pick them from the system dialog. Each completed file produces a plain text TXT file, a SubRip SRT file, and a WebVTT VTT file right next to the original media.

Built for offline reliability

Queue state and SHA-256 content hashes persist in queue_state.json so unfinished files resume automatically if the app restarts.
