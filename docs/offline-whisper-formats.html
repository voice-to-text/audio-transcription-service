Supported formats, language detection, and long audio

Pure-Rust audio decoding paired with energy voice activity segmentation and multilingual whisper.cpp inference.

MP3, WAV, M4A, and MP4 decoding

Media files are decoded locally using Rust symphonia (supporting MP3, PCM and float WAV, AAC inside M4A, and audio tracks inside MP4 containers) and resampled to 16 kHz mono 16-bit PCM for Whisper. If a specialized container requires extra demuxing, the pipeline falls back to local ffmpeg when installed. Any unsupported file extension or truncated stream raises UNSUPPORTED_FORMAT or CORRUPTED_FILE in the Error Log without halting other jobs.

English, Russian, and mixed speech detection

Each speech chunk passes -l auto to whisper-cli. After all chunks complete, the language classifier inspects Whisper's detected language code alongside Cyrillic and Latin character counts across all segments. Recordings containing substantial phrases in both Russian and English are labeled mixed (ru+en).

Silence detection and 1-hour VAD chunking

Before running inference, the audio engine computes per-100 ms RMS energy across the entire recording:

  • Pure silence recordings below the energy floor skip Whisper completely so zero hallucinated phrases appear, exporting empty TXT and clean WEBVTT files.
  • Recordings longer than 29 seconds split on quiet pauses into active chunks up to 26 seconds long. Each chunk retains its exact millisecond offset so exported SRT and VTT timestamps stay aligned across 5-minute and 1-hour files.
