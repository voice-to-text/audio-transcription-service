Pure-Rust symphonia decoding paired with energy VAD segmentation and multilingual whisper.cpp.

MP3, WAV, M4A, and MP4 decoding

Media files decode locally via Rust symphonia (with ffmpeg fallback if installed) and resample to 16 kHz mono PCM.

English, Russian, and mixed speech

Each speech chunk runs whisper-cli -l auto, and the classifier inspects Whisper language codes alongside Cyrillic and Latin letter counts.

1-hour VAD chunking and silence gate

Recordings split on quiet pauses into chunks up to 26 seconds with exact millisecond offsets, while pure silence skips inference.
