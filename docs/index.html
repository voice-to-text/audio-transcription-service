Core capabilities

Drag and drop queue

Drop MP3, WAV, M4A, or MP4 files into the studio window. Watch live per-file progress and inspect corrupted files or access issues in the Error Log.

Supported formats

Watch Folder automation

Point the studio at a folder. It waits until file copies finish, ignores duplicates via SHA-256 hashes, and writes TXT, SRT, and VTT next to each file.

Watch Folder guide

Synced media playback

Click any timestamped line in the transcript viewer to seek the built-in audio or video player directly to that second and adjust playback speed.

Frequently asked questions

Does Audio Transcription Studio require internet access or API keys?

No. Audio decoding, voice activity segmentation, Whisper speech recognition, and subtitle export run locally on your machine.

How does it handle Russian, English, and mixed-language recordings?

Each speech chunk runs with automatic language detection in whisper.cpp, and the language classifier inspects both Whisper metadata and Cyrillic/Latin scripts to label English, Russian, or mixed recordings.

What happens if the app closes while transcribing a queue?

Queue items and processed file hashes are saved to disk. Reopening the app resets unfinished items back to the queue and resumes processing automatically.
