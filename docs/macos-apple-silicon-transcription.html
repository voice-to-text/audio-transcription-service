Offline Whisper transcription on macOS

Install via DMG or build from source on Apple Silicon with Metal acceleration through whisper-cli.

Download Release View on GitHub

Lightweight native bundle

Built with Tauri 2 and Rust, the macOS .app bundle compiles to under 6 MB without shipping an Electron runtime.

Metal GPU acceleration via whisper.cpp

Homebrew whisper-cli uses Apple Metal automatically on M-series Macs for fast local transcription.

FSEvents Watch Folder integration

The directory watcher hooks into macOS FSEvents and stores persistent queue state in ~/Library/Application Support/Audio Transcription Studio.

brew install whisper-cpp && npm run tauri build
