Handle background noise, multiple speakers, and silence

Built-in RMS energy analysis prevents Whisper silence hallucinations and segments multi-speaker pauses.

Download Release View on GitHub

Pure silence gate

If every 100 ms window stays below the RMS energy and peak threshold, Whisper is skipped and empty TXT/SRT/WEBVTT files are exported with zero fabricated words.

Background noise resilience

Recordings with steady room tone or pink noise pass through Whisper with -sns non-speech token suppression enabled.

Multi-speaker pause splitting

Natural pauses longer than 550 ms split dialogue turns into separate chunks so alternating speakers transcribe cleanly.

max_rms < 0.0012 && max_peak < 120 -> is_silent: true (0 hallucinations)
