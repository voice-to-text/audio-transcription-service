Offline Whisper transcription on Windows

Transcribe MP3, WAV, M4A, and MP4 files on Windows without external codec packs or flashing console windows.

Download Release View on GitHub

Zero external codecs required for standard files

Pure-Rust symphonia decodes MP3, WAV, M4A, and MP4 audio tracks natively on Windows without requiring users to configure system codecs.

Silent background subprocess execution

Calls to whisper-cli.exe apply the Windows CREATE_NO_WINDOW creation flag so background queue workers never pop up console windows.

AppData persistence and ReadDirectoryChangesW

Queue state persists in %APPDATA%\Audio Transcription Studio while Watch Folder monitors directories via ReadDirectoryChangesW.
