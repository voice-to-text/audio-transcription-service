Generate WebVTT captions from audio

Export standard WEBVTT files for web players and documentation portals alongside TXT and SRT.

Download Release View on GitHub

Spec-compliant WEBVTT header

Every VTT export begins with the WEBVTT header followed by HH:MM:SS.mmm cues using dot separators.

Clean handling of silent files

If a recording contains only silence, the exporter writes a valid empty WEBVTT header without hallucinated cues.

Instant preview in the studio

Switch between Timestamped Segments, TXT, SRT, and VTT tabs in the right pane without opening an external text editor.
