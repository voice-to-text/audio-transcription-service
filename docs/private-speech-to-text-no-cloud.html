No accounts and no telemetry

Audio Transcription Studio does not ask for registration, credit cards, or API keys. Nothing leaves localhost: media streaming for the built-in player uses a loopback server on 127.0.0.1:4895.

Sidecar exports stay beside your files

Transcripts never sit in a third-party web dashboard. Every TXT, SRT, and VTT file writes atomically into the same folder as your source audio or video.

Permission-safe error isolation

If a folder is read-only or restricted, the exporter logs PERMISSION_DENIED and continues processing the rest of your batch.
