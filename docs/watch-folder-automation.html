Watch Folder automation and copy stability

Pick a folder once and let the studio transcribe every incoming recording after copying completes.

Download Release View on GitHub

Waiting for file copy completion

Copying a large MP4 or MP3 into a watched folder can take several seconds. Audio Transcription Studio checks byte size across consecutive 350 ms ticks and waits at least 700 ms after size stops changing before queuing.

Ignored temporary and output files

Dotfiles, browser partial downloads (.part, .crdownload, .tmp), and generated exports (.txt, .srt, .vtt) are ignored automatically.

Sidecar exports and permission checks

Completed transcriptions write TXT, SRT, and VTT next to the source file. If a folder loses write permission, PERMISSION_DENIED logs to the Error Log.
