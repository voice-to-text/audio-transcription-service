Native AAC inside M4A containers

iPhone Voice Memos, macOS QuickTime recordings, and mobile recorders save AAC audio inside M4A containers. Symphonia demuxes the ISO MP4 container and decodes AAC locally.

Watch Folder sync workflow

Point Watch Folder at a synced Voice Memos export folder. New M4A files wait for copy completion and export TXT, SRT, and VTT automatically.

Duplicate-safe re-imports

If the same M4A file is dropped twice or copied under another name, SHA-256 tracking marks it Skipped (Duplicate) instead of running Whisper again.

voice_memo.m4a -> voice_memo.txt + voice_memo.srt + voice_memo.vtt
