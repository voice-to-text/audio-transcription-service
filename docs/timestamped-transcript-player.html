HTTP 206 byte-range streaming

A local server on 127.0.0.1:4895 serves local media with Accept-Ranges: bytes and 206 Partial Content responses so seeking works cleanly across 1-hour files.

Active segment tracking

As playback progresses, the segment matching the current millisecond highlights automatically.
